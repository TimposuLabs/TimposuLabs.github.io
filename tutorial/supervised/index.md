# Supervised Learning

**Supervised Learning** adalah salah satu jenis Machine Learning yang memungkinkan komputer belajar dari data yang sudah memiliki label atau jawaban.

Bayangkan kita ingin membuat model yang dapat membedakan gambar kucing dan anjing. Kita memberikan banyak gambar kepada model beserta labelnya. Dari contoh tersebut, model belajar mengenali pola yang membedakan keduanya.

Setelah belajar, model dapat digunakan untuk memprediksi label pada gambar baru yang belum pernah dilihat sebelumnya.

## Contoh Supervised Learning

Supervised Learning dapat diterapkan dalam berbagai bidang, misalnya:

- **Prediksi harga rumah:** memperkirakan harga rumah berdasarkan luas, lokasi, dan karakteristik lainnya.
- **Klasifikasi email:** membedakan email spam dan bukan spam.
- **Deteksi penyakit:** membantu memprediksi kemungkinan penyakit berdasarkan data yang tersedia.
- **Prediksi cuaca:** memperkirakan kondisi cuaca berdasarkan data historis.

## Dua Jenis Utama Supervised Learning

Supervised Learning umumnya dibagi menjadi dua jenis:

| Jenis | Tujuan | Contoh |
|---|---|---|
| **Classification** | Memprediksi kategori atau kelas | Spam atau bukan spam |
| **Regression** | Memprediksi nilai numerik | Harga rumah |

Keduanya menggunakan data berlabel untuk mempelajari pola, tetapi memiliki jenis hasil prediksi yang berbeda.

## Kesimpulan

Supervised Learning memungkinkan model Machine Learning belajar dari data yang telah memiliki jawaban. Setelah mempelajari pola dari data tersebut, model dapat digunakan untuk membuat prediksi pada data baru.

Konsep ini menjadi dasar untuk mempelajari berbagai algoritma Machine Learning, khususnya Classification dan Regression.
