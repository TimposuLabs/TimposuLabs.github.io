# Javascript Dasar

## Pengantar JavaScript Dasar

Sebelum mempelajari React, penting untuk memahami dasar-dasar JavaScript terlebih dahulu. React dibangun di atas JavaScript modern, sehingga banyak konsep yang digunakan dalam React berasal langsung dari bahasa tersebut.

Pada bagian ini, kita akan mempelajari konsep-konsep JavaScript yang paling sering digunakan dalam pengembangan aplikasi React, seperti **variabel**, **tipe data**, **operator**, **function**, **object**, **array**, **destructuring**, **spread operator**, **arrow function**, **module**, hingga **asynchronous programming**.

Anda tidak perlu jago JavaScript untuk mulai belajar React. Namun, dengan memahami konsep-konsep dasar tersebut, Anda akan lebih mudah mengikuti setiap materi dan memahami cara kerja React dalam membangun aplikasi web modern.

Mari kita mulai dengan mempelajari dasar-dasar JavaScript sebagai fondasi sebelum memasuki dunia React.
