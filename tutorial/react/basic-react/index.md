# React Dasar

Setelah memahami dasar-dasar JavaScript modern, sekarang saatnya kita mulai mempelajari **React.js**.

React adalah library JavaScript yang digunakan untuk membangun **user interface (UI)**, terutama aplikasi web yang interaktif dan dinamis. React dikembangkan oleh Meta dan menggunakan pendekatan berbasis **component**, sehingga antarmuka aplikasi dapat dibangun dari bagian-bagian kecil yang dapat digunakan kembali.

Pada seri ini, kita akan mempelajari React.js dari dasar, mulai dari memahami konsep **component, JSX, props, state, event handling**, hingga bagaimana menampilkan dan mengelola data dalam aplikasi React.

Sebelum masuk ke konsep yang lebih lanjut, penting untuk memahami bagaimana React bekerja dan mengapa React menggunakan pendekatan berbasis component.

## Apa yang Akan Dipelajari?

Dalam materi React.js dasar ini, kita akan membahas:

* Pengenalan React.js dan cara kerjanya
* Membuat React Project
* Mengenal **JSX**
* Membuat dan menggunakan **Component**
* Mengirim data menggunakan **Props**
* Mengelola data menggunakan **State**
* Menangani **Event**
* Membuat aplikasi React sederhana
* Dan lainnya.

Dengan memahami konsep-konsep dasar tersebut, kita akan memiliki fondasi yang cukup untuk melanjutkan ke materi React yang lebih lanjut seperti **React Hooks, API, routing, state management, hingga integrasi dengan backend**.

Mari kita mulai dengan memahami **apa itu React.js dan mengapa React banyak digunakan dalam pengembangan aplikasi web modern**.
